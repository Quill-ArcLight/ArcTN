# Security

Only load `ARCTN_ENGINE_LIBRARY` from a trusted provider. Loading a native
library executes code with the permissions of the current process.

For security-sensitive reports, use the repository's private vulnerability
reporting facility when available. Do not post credentials, private engine
files, or confidential inputs in a public issue.

Maintainer: liuxl. Report vulnerabilities privately to quill@arclightquantum.com.
Include the version, platform, reproduction steps and whether a separate engine
was loaded. Do not attach confidential inputs or engine binaries to public Issues.
There is no guaranteed response or remediation time.
